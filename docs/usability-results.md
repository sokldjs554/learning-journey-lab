# 데모 사용성 검토와 문구 개선

2026-10-30 KST. **참여자 1명의 네 과제 응답을 진행자를 통해 받았다. 검증 계획의 문구를 수정했으며, 수정 후 참여자 재검토는 아직 미실시다.** 이해도 향상·전체 사용자 성공률·제품 리텐션 효과를 주장하지 않는다.

## 수행과 공개 범위

- 지원자가 참여자를 모집하고 과제를 전달했으며, 응답·이동 경로·도움 여부를 Codex에 전달했다. 네 과제 모두 도움 없음으로 보고했다. Codex가 화면을 직접 관찰하거나 녹화한 검토는 아니다.
- 참여·익명 기록 동의에 이어, 이름·연락처·직접 인용 없이 발견한 문제를 공개 GitHub에 요약하는 데 동의했다고 진행자가 확인했다. 이 문서는 그 범위의 요약이다. 원문 발언·개인 식별 정보는 게시하지 않는다.
- 장치: 노트북·Chrome. 브라우저 버전·OS·화면 크기·정확한 클릭 순서·과제별 시간은 기록하지 못했다. 사전 이용 경험·직무 숙련도는 별도로 조사하지 않았다.
- 과제는 [사전에 정한 네 문항](novice-usability-protocol.md)을 사용했다. 검토 시점의 화면은 `764406ff5b4bf4c4ccf467bea905747fb1bbedf3`와 같은 web 파일이다. 참여자의 브라우저 캐시까지 확인한 것은 아니다.

## 전달받은 결과

| 과제 | 이동·설명의 요약 | 응답에 근거한 판정 |
|---|---|---|
| 1. 프로젝트 목적 | 품질 규칙의 판단 기록을 살펴보고 관측·판단 역할을 언급. 일반적인 수강 관련 시스템과의 차이에 의문을 제기 | 학습 재방문과 로그 품질의 연결을 충분히 이해했는지는 미확인. 차별점 전달을 검토할 단서 |
| 2. 369건 해석 | 동일값 반복 → 지표 영향. 처리 정책에 따른 10클릭 기준 충족 수강 건의 분류 변경으로 설명 | 진행자 보고 기준 핵심 의미를 도움 없이 설명. 삭제된 로그 수나 고유 사용자 수로 설명하지 않음 |
| 3. 판단과 반대 근거 | 재방문 근거 화면에서 강좌 맥락·학습 목적의 추가 확인 필요성을 언급 | 추가 확인 필요성은 설명. 구체적인 관찰 수치·반대 근거를 찾아 해석했는지는 미확인 |
| 4. 다음 검증 구분 | 검증 계획에서 세 항목의 제목을 찾았으나 의미를 이해하기 어렵다는 응답 | 제목 발견은 확인. 무엇을 비교하고 무엇이 아직 미검증인지 구분하는 완료 기준은 전달된 답변에서 충족하지 못함 |

전달된 응답에 없는 이해를 추정해 성공으로 채우지 않았다. 1·3번의 판정 보류를 실패율로 합산하지 않으며, 시간·성공률의 개선 수치를 만들지 않는다.

## 수정한 내용과 이유

4번은 항목을 찾고도 뜻을 이해하지 못했다는 구체적인 보고가 있어 먼저 수정했다. 새로운 기능이나 분석 방법을 추가하지 않고 기존 검증 계획의 설명을 고쳤다. 1번의 차별점 의견만으로 화면 전체를 다시 설계하지 않았다.

| 기존 화면 제목 | 수정 제목 | 함께 보완한 설명 |
|---|---|---|
| 계측 계약과 수신 대조 | 학습 기록의 누락 확인 | 기록이 빠지거나 중복되었는지 확인하는 준비 단계. 생성 자료 검사는 완료, 실제 서비스 기록 대조는 미실시 |
| 다음 학습 진입점 실험 | 다음 학습 안내 비교 | 이어 들을 위치를 안내하는 화면과 현재 화면을 비교하는 제안. 설계만 완료했으며 실제 비교·재방문 개선 효과는 미검증 |
| 콘텐츠 접촉 확대 보류 | 콘텐츠 노출 확대 보류 | 개설기별 방향 차이 때문에 전체 평균만으로 확대하지 않는 판단. 먼저 확인할 강좌·학습 맥락을 명시 |

생성 데이터의 검사 통과가 실제 사용자 효과를 뜻하지 않는다는 설명도 앞에 배치했다. 대상·분모·D7–13 관측 창·무작위 배정·중단 조건·부작용 점검은 유지했다. 수정 파일은 [index.html](../web/index.html), [catalog.js](../web/catalog.js), [experiment-view.js](../web/experiment-view.js)다. 수치·SQL·분석 결과와 공개/생성 자료 구분은 바꾸지 않았다.

## 누가 수행했는가

- **지원자:** 참여 가능·동의 확인, 과제 진행, 실제 응답·경로·도움 여부 전달, 익명 요약 공개 동의 확인.
- **참여자:** 네 과제에 응답하고 이해하기 어려운 부분을 전달한 것으로 진행자가 보고.
- **Codex:** 과제 안내·기록 양식 제공, 전달된 응답의 판정과 한계 정리, 문구 수정·기술 검증·배포. 지원자가 UI 코드를 직접 고쳤다고 기록하지 않는다.

## 남은 재검토

수정된 공개 화면에서 같은 참여자에게 **다음에 무엇을 실험하려는지와 아직 실제로 검증하지 않은 것을 구분해 달라**는 기존 4번 과제를 다시 전달한다. 정답이나 변경한 문구를 먼저 설명하지 않는다. 본인 말로 설명한 내용·이동 경로·도움·남은 어려움을 기록한다.

같은 사람은 이전 과제에서 학습했을 수 있다. 재검토에서 설명이 나아져도 문구 변경만의 인과 효과나 신규 사용자의 이해도로 일반화하지 않는다. 참여자 1명의 편의 모집 결과이며 CLASS101 고객·데이터 분석가를 대표한다고 가정하지 않는다. 이번 사용성 검토는 학습 안내 기능의 실제 A/B 실험이나 재방문·매출 검증이 아니다.
