## 개발 중 수정한 작은 오류

- SQL 별칭 `content`에서 파서 오류가 발생해 `has_content`로 수정; 손계산 지표 테스트로 회귀 확인.
- 초기 브라우저 실패 테스트가 Playwright route 콜백의 두 번째 Request 인자를 payload로 받아 테스트 자체가 실패. 인자를 명시적으로 분리하고 **이전 JS를 주입한 브라우저에서 5개 실패를 확인한 뒤** 수정 JS에서 6개 통과를 확인했다. 테스트 도구 오류를 제품 결함 증거로 세지 않았다.
- 전체 페이지 캡처 직전에 부드러운 스크롤이 진행돼 사이드바가 중간 위치에 기록됨. reduced-motion 및 즉시 스크롤, 별도 첫 화면 캡처로 교정. 제품 계산 결과에는 영향 없음.
- 이 환경의 기본 사용자 cache 경로에 브라우저/npm 설치가 실패해 작업용 `work/` 경로에 설치. 저장소 코드에는 개인 cache 경로를 하드코딩하지 않았다.

## 남은 불확실성

반복 행의 원천 의미와 탈퇴 후 활동 원인은 확인되지 않았다. OULAD에 없는 누락을 알아냈다고 주장하지 않는다. 강좌 일정·학습 동기·서비스 차이를 제거하지 못했다. 실제 사용자 관찰, 개선 실험, 구독 유지 측정은 후속 작업이다.
