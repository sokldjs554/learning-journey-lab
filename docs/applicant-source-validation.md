# 지원자 원본 검증 코드 제출·검토

2026-11-05 KST. 지원자가 `validate_sources.py`를 첨부하고 [직접 구현 요구사항](independent-implementation-brief.md) 링크를 함께 보냈다. **첫 모듈의 코드 제출과 기능 검토를 완료했다. 제출본은 수정하지 않았다.** 코드 작성 현장을 관찰한 것은 아니며, 함께 보낸 링크가 유일한 참고 자료라고 추정하지 않는다.

[제출 원본](../evidence/applicant/validate_sources.py) · [실행 결과와 출처](../reports/applicant-source-validation.json) · [Codex가 작성한 검토 테스트](../tests/test_applicant_validate_sources.py).

## 제출 코드가 하는 일

- `--manifest`, `--csv-dir`로 두 경로를 받아 실행한다.
- manifest가 정확히 OULAD 7개 파일을 포함하는지, 각 SHA-256이 64자리 16진수인지, bytes가 음수가 아닌 정수인지 검사한다. bool을 정수 크기로 받지 않는다.
- CSV를 1MiB씩 읽어 해시와 실제 바이트 수를 계산한다. 파일 전체를 메모리에 한꺼번에 올리지 않는다.
- 파일별 성공·실패와 원인을 출력하고, 모두 일치하면 종료 코드 0, CSV 문제는 1, manifest 읽기·형식 오류는 2로 끝낸다.
- CSV와 manifest를 읽기 전용으로 열며 다운로드·덮어쓰기·생성 자료 대체를 하지 않는다.

위 설계는 제출 코드에서 관찰한 동작이다. 지원자가 이유를 말로 설명한 발언으로 대신 기록하지 않는다.

## Codex 실행 검증

| 검사 | 입력과 기대 | 결과 |
|---|---|---|
| 실제 공개 원본 | 고정 manifest와 캐시된 실제 OULAD 7 CSV | 성공 7건 / 실패 0건, 종료 0 |
| 정상 소형 자료 | 7개 파일을 각각 `abc` 3바이트로 생성, 알려진 SHA-256 기준값 사용 | 파일별 성공 7개, 종료 0 |
| 누락·폴더 오류 | CSV 하나 누락, CSV 대신 디렉터리, 원본 폴더 없음 | 파일/원인 표시, 종료 1 |
| 내용 변조·크기 | `abc`→`abd`로 길이 유지 변조; 별도 사례에서 선언 크기만 다르게 지정 | 각각 해시 불일치/크기 불일치 표시, 종료 1 |
| manifest 계약 오류 | 파일 목록 누락/추가, 잘못된 SHA, bool/음수 크기, 객체가 아닌 자료, 깨진 JSON | manifest 오류 표시, 종료 2 |
| 대문자 해시 | 정상 해시의 대문자 표기 | 정상 통과 |
| 읽기 방식 | 파일 대신 추적 가능한 시험 객체로 여러 번 읽기와 최대 1MiB 요청 확인 | 알려진 `abc` 해시와 크기 일치 |

자동 검사 총 **15개 통과**. 작은 검사 파일은 Codex가 임시 폴더에 만든 시험 자료이며 실제 학습자 데이터가 아니다. 실제 원본 실행 전후에도 각 CSV의 SHA-256과 수정 시각을 비교해 변경이 없음을 확인했다. 업로드 파일과 보존 파일의 바이트도 일치한다.

제출 원본 SHA-256: `2bbaf17052cd73575edce5de3f5200d6d6bc07934cb3b25730301e4263665444`.

## 역할과 범위

- 지원자: Python 파일 제출, 요구사항 문서 링크 전달. 이번 첨부와 함께 본인의 실행 출력이나 별도 설계 설명을 보낸 것은 아니다.
- Codex: 원본 보존, 15개 테스트 작성·실행, 실제 OULAD 실행, 결과 검산·문서 정리·커밋. 제출 코드의 논리를 수정하거나 대신 작성하지 않았다.
- 이 모듈은 제공된 manifest와 파일이 일치하는지 확인한다. manifest 자체의 진위, CSV 행의 의미·키·날짜 정합성까지 입증하지는 않는다. 이는 이후 SQL 품질 검사와 구분된다.
- 첫 모듈의 기능 검토를 완료한 것이며 UI·배포를 포함한 전체 직접 구현 완료로 확대하지 않는다. 기존 SQL·손계산·판단과 v2 사람 실측의 완료 상태는 유지한다. 이번 검토에서 발견하지 않은 결함이나 수정 이력을 만들어내지 않는다.

## 재현

현재 프로젝트 의존성이 있는 환경에서:

```bash
python -m pytest -q tests/test_applicant_validate_sources.py
python evidence/applicant/validate_sources.py --manifest data/manifest.json --csv-dir /실제/원본/CSV/폴더
```

두 번째 명령의 원본 경로는 실행 환경에 맞춰 바꾼다. 이는 재현 참고이며 이미 통과한 검토를 반복 제출해야 하는 추가 완료 조건이 아니다.
