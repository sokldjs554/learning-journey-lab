지원자는 안내된 코드·원본·패키지가 존재함과 초기화 완료를 보고했다. Codex가 안내한 ZIP은 커밋 `53afb3fff20b43ea206225008d2ce42f0a037cc8`이다. 원본 protocol과 코드 지문은 받지 않았으므로 그 커밋이 실제 사용됐다고 독립 인증하지 않는다. 이번 Python 버전·경로 출력도 받지 않았으며 앞선 실습의 Python 3.14를 이번 버전으로 대신 기입하지 않는다.

연습 A는 1회 중단 뒤 완료했고 연습 B도 완료했다. 본 측정은 A→B→B→A→A→B 순서로 완료했다. 5회차 A에서 중단 후 재시도한 기록을 포함한다. 전체 10시도 중 연습 3시도, 본 측정 7시도다. 누적 입력 수정 3건·중단 2건 중 연습은 수정 2건·중단 1건, 본 측정은 기록된 입력 오류 1건·중단 1건이다. 요약에는 각 중단 사유가 없어 오류가 중단을 일으켰다고 단정하지 않는다.

- 지원자 로컬 도구가 출력한 `audit: PASS`, `completed_measured: 6`, `next: null`을 확인했다. 합의한 종료 기준을 충족했다.

## 해석과 역할

고정된 작업에서 직접 기록 방식과 자동 채움 방식의 관측 시간이 달랐다. 한 사람의 같은 자료 반복이며 앞선 v1·연습 경험, 순서, 전사 부담과 중단의 영향을 분리할 수 없다. **v1→v2의 인과적 시간 절감률이나 회사 생산성 개선으로 해석하지 않는다.** 자동 채움 B에서 `reviewed` 입력이 있었다는 사실만으로 동일한 검토 깊이를 입증하지 않는다. 이번 본 측정의 완료된 시도에는 입력 오류가 없어서 사람의 오류 수정 후 같은 회차 완료 효과를 입증했다고도 쓰지 않는다. 그 동작은 별도 개발 자동 검사에서 확인한 사항이다.

지원자는 직접 측정과 감사 출력 전달을, Codex는 기존 도구 구현·실행 안내·검산·문서 정리·커밋을 담당했다. 이번 실측 종료는 기존의 SQL 직접 작성·손계산·실행·판단 완료 근거와 함께 유지한다. 사용자가 별도로 선택한 UI·배포 포함 독립 재구현은 별도 과제이며 이번 시간 측정으로 완료했다고 표시하지 않는다.
