# SQL 판단 과제와 안내 실습 결과

상태: **2026-11-04 안내 실습 종료**. 처음에는 독립 과제로 제시했으나 사용자가 작성·실행 방법을 요청해 Codex가 완성 SQL과 필터 수정 예제를 제공했다. 이후 받은 실행 결과는 안내 실습의 근거이며 독립 작성의 증거로 전환하지 않는다.

## 실제 수행 결과

지원자는 분석표 검색 결과를 전달했고, Codex는 `work/full-operations/calibration/work/enrollment_mart.csv`를 읽도록 안내했다. `duckdb` 모듈 오류 보고 후 기존 가상환경 확인 방법을 안내했으며 이후 전체 29,671건과 개설기별 44행 출력, BBB·2014J로 제한한 2행 출력을 받았다. 로컬 화면을 Codex가 직접 관찰한 것은 아니다.

| BBB·2014J 첫 주 활동 | 분모 | 다음 주 활동 분자 | 재방문율 |
|---|---:|---:|---:|
| 1일 | 484 | 330 | 68.2% |
| 2일 이상 | 986 | 834 | 84.6% |

저장소 보고서의 동일 개설기 집계와 대조했다. 합계 1,164/1,470=79.2%. 전체 29,671건 출력은 별도 COUNT 쿼리여서 개설기 필터와 무관하게 유지된다. [구조화 근거](../reports/guided-sql-practice.json).

분모를 재방문자로 먼저 제한하는 오류에 대한 질문에는 사용자가 기존 두 비율을 답했고, Codex가 330/330=100%가 되는 이유를 설명했다. 이 설명을 지원자가 독립 도출한 것으로 기록하지 않는다. 이후 필터 적용 결과는 받았으나 본인 말로 된 범위 설명과 수정 SQL 파일은 받지 않았다. 합의한 안내 실행·수정 실습은 여기서 끝내며 독립 역량 인증이나 추가 과제의 자동 연장으로 취급하지 않는다.

아래는 최초 과제의 질문과 계획이다. 당시 계획한 무힌트 독립 제출 절차를 완료한 것으로 해석하지 않는다.

## 한 가지 질문

첫 주 활동이 있는 수강 건만 대상으로, 개설기별 **1일 / 2일 이상** 활동군의 분모·다음 주 활동 분자·재방문율을 구한다. 한 개설기는 강좌와 개설기 코드의 조합이다. 행 단위는 사람 전체가 아닌 수강 건이다.

| mart 열 | 뜻 |
|---|---|
| code_module | 강좌 코드 |
| code_presentation | 개설기 코드 |
| id_student | 학습자 ID. 다른 강좌·개설기에서 다시 등장할 수 있음 |
| w1_days | 첫 주 활동일 수, 0~7 |
| w2_active | 다음 주 활동 여부, 0 또는 1 |

전체 분석의 기존 적격성·결측 처리는 이미 mart 생성 시 적용되어 있다. 이 과제는 원본 로그 정제부터 새로 설계하는 과제가 아니다. 기존 `work/enrollment_mart.csv`가 이 분석표이며, 파일이 없어도 SQL을 대화로 제출할 수 있다. 환경 설치나 원본 재다운로드를 먼저 요구하지 않는다.

## 제출과 검토

1. 직접 작성한 SQL과 분모를 그렇게 정한 이유를 보낸다. 완성되지 않았으면 작성한 부분과 막힌 지점을 보낸다.
2. 문법 문서·기존 코드·AI 등 참고한 자료와 도움의 범위를 함께 적는다. 도움을 받았다고 실패 처리하지 않고 근거의 범위를 구분한다.
3. Codex는 제출본을 먼저 보존하고, 0일 제외·개설기 키·중복 학습자·정수 나눗셈·분모/분자를 검토한다. 손으로 확인 가능한 별도 사례 및 기존 mart와 대조한다.
4. 피드백 뒤 수정은 최초 독립 시도와 별도 기록한다. 결과를 보고 본인이 설명한 내용만 참여 기록에 추가한다.

최초 계획은 정답 SQL을 먼저 제공하지 않는 것이었다. 이후 요청에 따라 예제를 제공했으므로 이번 결과는 완전한 무힌트 독립 과제가 아니다. 이 한 실습으로 전체 SQL 숙련도나 통계 설계 능력을 인증하지 않는다.
