# 독립 SQL 판단 과제

상태: **과제 제공, 제출 대기**. Codex가 문제를 준비했다. 지원자가 SQL을 작성·실행·설명했다는 뜻이 아니다. 기존 안내받은 실습과 별도 기록한다.

## 한 가지 질문

첫 주 활동이 있는 수강 건만 대상으로, 개설기별 **1일 / 2일 이상** 활동군의 분모·다음 주 활동 분자·재방문율을 구한다. 한 개설기는 강좌와 개설기 코드의 조합이다. 행 단위는 사람 전체가 아닌 수강 건이다.

| mart 열 | 뜻 |
|---|---|
| code_module | 강좌 코드 |
| code_presentation | 개설기 코드 |
| id_student | 학습자 ID. 다른 강좌·개설기에서 다시 등장할 수 있음 |
| w1_days | 첫 주 활동일 수, 0~7 |
| w2_active | 다음 주 활동 여부, 0 또는 1 |

전체 분석의 기존 적격성·결측 처리는 이미 mart 생성 시 적용되어 있다. 이 과제는 원본 로그 정제부터 새로 설계하는 과제가 아니다. 기존 `work/enrollment_mart.csv`가 이 분석표이며, 파일이 없어도 SQL을 대화로 제출할 수 있다. 환경 설치나 원본 재다운로드를 먼저 요구하지 않는다.

## 제출과 검토

1. 직접 작성한 SQL과 분모를 그렇게 정한 이유를 보낸다. 완성되지 않았으면 작성한 부분과 막힌 지점을 보낸다.
2. 문법 문서·기존 코드·AI 등 참고한 자료와 도움의 범위를 함께 적는다. 도움을 받았다고 실패 처리하지 않고 근거의 범위를 구분한다.
3. Codex는 제출본을 먼저 보존하고, 0일 제외·개설기 키·중복 학습자·정수 나눗셈·분모/분자를 검토한다. 손으로 확인 가능한 별도 사례 및 기존 mart와 대조한다.
4. 피드백 뒤 수정은 최초 독립 시도와 별도 기록한다. 결과를 보고 본인이 설명한 내용만 참여 기록에 추가한다.

정답 SQL과 작성 완료 기록은 미리 넣지 않는다. 현재 저장소의 SQL을 먼저 읽었다면 그 사실을 남기며, 완전한 무힌트 독립 과제로 포장하지 않는다. 이 한 문제로 전체 SQL 숙련도나 통계 설계 능력을 인증하지 않는다.
