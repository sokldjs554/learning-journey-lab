## 직접 수행 결과가 필요한 항목

추가 진행 요청에 따라 [실제 진행 절차](remaining-validation-execution.md)를 준비했다. 사용자는 맥북·안드로이드와 Python·SQL 설치·실행 경험을 보고했다. 직접 CI 화면 확인과 Safari·Android·VoiceOver 일부 과제는 사용자 응답으로 확인했다. 이후 Python 3.14 맥북의 공개 원본 재현·독립 대조·보고서 일치, SQL 결측 45행 확인과 판단 설명을 받았다. 기존 명령 재실행·세 결과 확인은 1회 100초로 보고됐다([직접 참여](participation.md), [계측 범위](local-rerun-results.md)). 회사 권한은 획득 방법을 안내했으며 확보된 것으로 기록하지 않는다. 절차 준비를 실제 수행 완료로 집계하지 않는다.

| 항목 | 확인된 현재 상태 | 다음 확인과 완료 기준 |
|---|---|---|
| 처음 보는 참여자 사용성 | 1명의 네 과제 응답·도움 없음 보고와 익명 요약 공개 동의 확인. 검증 계획 문구 수정 | [결과와 한계](usability-results.md). 수정 후 4번 재검토 응답 수신. 더 읽기 편하다는 평가·추가 질문 뒤 목적 설명 확인. 실제 실험 미실행 구분은 미확인. 문구 수정의 인과 효과는 주장하지 않음 |
| 지원자의 새 테스트 CI 읽기·코드 설명 | 파일 추가·커밋·안내받은 CI 결과 읽기 확인. 반복 초과 행 수라는 의미 설명 | [직접 참여](participation.md). 30개 통과는 실습 브랜치 당시 결과다. fixture의 `3−1=2` 설명은 Codex 도움이며 독립 설계·설명으로 세지 않음 |
| 기존 자동화 명령 재실행·결과 확인 | 지원자 1명·1회 전체 경과 100초, 세 결과 확인·오류·중단·계측 중 추가 도움 없음 보고 | [측정 결과](local-rerun-results.md). 실행 대기 포함, 사전 안내 있음. 수작업 분석 비교·절감 효과가 아님 |
| 전체 분석 수동 운영·일괄 실행 비교 | 사용자가 A 단계별 실행·직접 기록 / B 일괄 실행·같은 항목 검토 범위로 진행에 동의. 12단계·84개 공통 확인 도구와 개발자 동등성 검사 완료. 실제 사람 연습·본 측정은 대기 | [실제 절차](full-operations-protocol.md) · [개발 검증](full-operations-validation.md). 연습 AB 후 본 측정 ABBAAB. 순수 손계산·독립 코드 작성 비교가 아니며 기존100초와 혼합하지 않음 |
| 실제 Safari·물리 휴대폰·스크린 리더 | Safari 16.6.1·Samsung Internet 30.0.5.27의 지정 흐름과 VoiceOver 제목·선택·키보드·숫자 읽기 확인(사용자 보고) | [기기별 범위·숫자 정정](device-check-results.md). 모든 화면, 오류 음성 안내·출처 접근·TalkBack 등은 미확인. 전체 접근성 인증 아님 |
| CLASS101 실제 사용자 A/B·갱신·매출 효과 | 미실시. 공개 자료 분석·실험 설계·합성 입력 검사는 완료 | 서비스 운영 권한, 배정·동의·로그 품질·관측 기간과 실제 결과 필요. 외부 데모 사용성 참여자를 CLASS101 실험 참여자로 세지 않음 |

전체 사람 기준선을 시작할 때는 사용 중인 운영체제와 실행 가능한 도구부터 확인한다. 예를 들어 macOS/Linux 터미널은 `python3 --version`, Windows PowerShell은 `py --version`으로 확인할 수 있지만 설치되어 있다고 가정하지 않는다. 명령이 없으면 오류를 그대로 남기고 설치·학습은 측정에서 제외한다. 환경 없이 가능한 기존 GitHub Actions 실습은 자동 재현 확인이며 사람의 수작업 분석 시간 측정을 대신하지 않는다.

이 문서는 남은 일을 완료로 바꾸기 위한 양식이 아니다. 실제 과제 결과·장치 검토·사람 작업 기록을 받은 뒤 근거와 상태를 갱신한다.

## 전체 접근성 후속 검토

[WCAG 2.2 A·AA 55개 적용 기준](accessibility-criteria.md)에 따라 화면·상태 범위를 확장하고 재시도 초점·규칙별 필드명·입력 오류·표 스크롤·테두리 대비·문자 간격 결함을 보완했다. [기술 결과](accessibility-review-results.md)와 [실제 VoiceOver·확대 후속 과제](accessibility-human-checks.md)를 구분한다. 새 변경분의 사람 응답이 아직 없으므로 전체 완료나 인증으로 표시하지 않는다.
