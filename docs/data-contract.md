# 데이터 계약과 지표 사전

## 출처와 보존

OULAD, Open University. Kuzilek J., Hlosta M., Zdrahal Z. (2017), [doi:10.1038/sdata.2017.171](https://doi.org/10.1038/sdata.2017.171). [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 원본 출처·파일별 SHA256·byte 수는 `data/manifest.json`. 변환은 이 프로젝트에서 수행했으며 원저자 또는 CLASS101의 보증을 의미하지 않는다.

원본 7 CSV는 로컬 `data/raw/`에만 보관하고 git에서 제외한다. 공개 저장소와 데모는 집계 결과와 완전 생성 로그만 포함한다. 익명 학생 ID도 공개 UI에 노출하지 않는다. `data/synthetic/`는 OULAD에서 샘플링한 자료가 아니라 코드가 처음부터 만든 가상 자료다. 원본 파일이 없을 때 자동으로 생성 자료를 대신 사용하지 않는다.

## 단위와 시간

- **학습자**: `id_student`. 실제 고유 ID 수는 28,785.
- **수강 건**: `(code_module, code_presentation, id_student)`. 원본 32,593건. 학습자 수와 다르다.
- **개설기**: `(code_module, code_presentation)`, 22개. B/J는 각각 2월/10월 시작. 강좌 구성과 개설 일정이 달라 단순 비교의 교란 가능.
- **활동 행**: `(module, presentation, student, site, date, sum_click)`. 일 단위 요약이며 1행=1영상/1세션/1고유 이벤트가 아니다. 일별 키도 실제로 유일하지 않다.
- **날짜**: 해당 개설기의 개강일 D0 기준 상대 일수. 달력 날짜나 시간대별 자정으로 복원하지 않는다. 원본 -25~269일. 음수 날짜는 정상적인 사전 접근일 수 있다.
- W1=D0~6(양끝 포함), W2=D7~13, 후속=D14~27. 마지막 날 포함 여부를 테스트한다.

## 코호트 포함·제외

1. 등록일 결측 45건 제외. `?`와 빈칸을 null로 읽는다.
2. 개강 후 등록 234건 제외.
3. 등록일<=0이면서 개강 전 탈퇴 2,643건 제외. 단순 전체 사전 탈퇴 2,678과 다르며, 앞 단계와 중복을 제거한 순차 집계다.
4. 개설 길이>=28 조건. 이번 원본은 모든 개설기가 충족한다.
5. 남은 29,671 수강 건. 사후 탈퇴 여부로 분모를 다시 줄이지 않는다.

미래의 수료/탈퇴 결과·시험점수·전체 기간 클릭 수를 첫 주 설명 변수로 사용하지 않는다. 마지막 활동일을 '탈퇴 시점'으로 간주하지 않는다.

## 지표

| 지표 | 분자 | 분모·조건 | 해석 |
|---|---|---|---|
| W1 활성 | 유효 양수 클릭이 D0~6 중 하루 이상 | 코호트 전체 | 학습 자료 접근의 대리지표 |
| W2 재방문 | W1 활성 중 D7~13에 하루 이상 활동 | W1 활성 수강 건 | 계정 로그인 유지·구독 유지가 아님 |
| W1 활동일 | 양수 클릭이 있는 고유 상대 날짜 수 | 수강 건별, 0~7 | 행 중복의 영향을 받지 않는 존재 지표 |
| 2일+ vs 1일 차이 | 각 그룹 W2 재방문율의 차 | W1 활성 그룹별 분모 | 관찰적 차이, 인과 효과 아님 |
| 첫 활성일 콘텐츠 접촉 | 첫 활동 날짜에 oucontent/resource/subpage/page가 하나 이상 | W1 활성 수강 건 | 내용 중심 자료의 가설상 분류. 첫 이벤트/영상 재생은 아님 |
| 0일 그룹의 다음 주 활동률 | W1 비활성 중 W2 활성 | W1 비활성 | 재방문 주지표와 분모가 다름 |
| W3–4 활동 | D14~27 활동 존재 | 전환 구간별 수강 건 | 일시적 공백과 영구 이탈을 구분할 단서 |

'유효'는 양수 클릭, 등록 복합키와 콘텐츠 복합키 존재, 필수 날짜/ID 존재를 뜻한다. 차원 테이블 키가 중복이면 JOIN을 중단한다. BLOCK 품질 규칙 실패는 배포를 막는다. 원본의 등록 시점 경고는 기본 집계에서 보존하고 strict 대안을 비교한다.

## 반복 행 처리와 품질

- 완전 동일 값 반복 초과 행: 787,170. 반복 일별 키 초과 행: 2,195,960. 두 수는 포함 관계가 있으므로 더하지 않는다.
- 완전 동일 값: 모든 6개 원본 필드가 동일. 초과 행은 첫 행을 뺀 개수이며 고유 사건 오류 건수가 아니다.
- 원본 합산: 모든 행의 클릭 합.
- 동일 값 한 번: 같은 학습자·자료·날짜·클릭 값은 한 번만 합산. 이것이 진실이라는 가정 없음.
- 자료별 최대: 같은 학습자·자료·날짜에서 최대 클릭만 취하고 자료 간 합산. 보수적 민감도 시나리오, 정답 아님.
- 세 정책 모두 활동한 날짜의 존재를 동일하게 만든다. 따라서 주요 활동일 지표는 유지하되 클릭 임계값 분류의 변경 수를 공개한다.
- 탈퇴일 이후 29,440행, 기간 경계 이후 4,374행은 원인 미확정 경고. 강제로 삭제해서 '품질 개선' 성과로 만들지 않는다.
- 완전성은 원천 명세가 없어 검증 불가. 통과한 참조키 검사만으로 모든 로그가 수집됐다고 말할 수 없다.

각 규칙 SQL은 `sql/quality.sql`, 실행 결과는 `reports/report.json#/quality`, 규칙 단위 이력은 `reports/issues.json`. 여기서 open은 조사/정책 판단 필요라는 뜻이며 회사의 실제 장애 티켓이 아니다.

## 시간 분리와 선택 편향

2013년 탐색과 2014년 재확인을 분리하고, 원본 등록 테이블에 2013년 이력이 있는 모든 학습자를 재확인에서 제외한다. 코호트 부적격인 2013년 수강도 제외 근거에 포함한다. 데이터는 이미 공개돼 있었으므로 이 절차를 진정한 사전등록·블라인드 검증으로 부르지 않는다.

시작일이 늦으면 같은 첫 주 안에서 2일 활동할 기회가 줄어든다. 시작일별 비교를 제공하며 D6은 2일+ 그룹이 없어 비교 불가로 표시한다. 미래 W2를 W1 특징에 쓰지는 않지만, 두 주 모두 남아있기 쉬운 학습자의 자기선택과 동기·강좌 난이도·과제 일정 교란이 남는다. 개설기별 비교로 일부 이질성을 드러낼 뿐 제거하지 않는다.

## 불확실성

학습자 ID를 복원 추출하고 그 학습자의 모든 수강 건을 함께 계산하는 군집 부트스트랩. seed=101, 전체·시간 분리 1,000회, 개설기·최초 활동일 500회, 2.5/97.5 백분위. 반복 수강을 독립 표본으로 세지 않기 위한 선택이다. 개설기라는 상위 공통 환경의 불확실성, 미관측 교란, 2013–2014 영국 대학과 현재 한국 구독 서비스의 차이는 해결하지 못한다. 다중 비교 유의성 탐색이나 순위 확정에 사용하지 않는다.

DiD: 처치 시점·통제 집단 없음. DoubleML: 교란 통제 가정 보장 못함. SHAP: 설명할 예측 모델을 만들지 않음(그 자체도 인과 추론이 아님). Markov: 집계 날짜만 있고 일정 변화가 커 안정적인 전이 가정 부적합. 복잡한 방법 대신 해석 가능한 집계·민감도·실험 설계를 택했다.
