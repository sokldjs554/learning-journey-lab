# 로컬 재실행·결과 확인 시간

2026-10-31 KST. 지원자 1명이 맥북의 Python 3.14 가상환경에서 기존 분석 명령을 순서대로 실행하고 결과를 확인했다. **전체 경과 시간 100초, 측정 1회**라고 보고했다. 실행 대기를 포함한다. 이는 이미 자동화된 분석의 재실행·확인 기록이며 전체 분석을 수작업으로 수행한 시간이나 자동화 절감 효과가 아니다.

## 측정 전에 정한 작업

저장소 다운로드·가상환경 설치·원본 CSV 7개 다운로드·첫 실행 연습은 먼저 마쳤다. 같은 터미널에서 아래 명령을 하나씩 실행하고 세 가지 결과를 읽은 뒤 스톱워치를 멈추도록 안내했다. 준비 안내를 읽은 뒤 시작하며, 오류·중단이 생기면 숨기거나 재시작하지 않고 보고하도록 했다.

```bash
python scripts/analyze.py
python scripts/crosscheck.py
python scripts/build.py
python scripts/verify.py
```

| 확인 항목 | 사전에 안내한 기준 | 전달받은 결과 |
|---|---|---|
| 분석 | REVIEW, 적격 29,671·첫 주 활성 23,522·다음 주 재방문 20,303 | 확인했다고 보고 |
| 독립 대조 | mismatched_rows 0 | 확인했다고 보고 |
| 보고서 일치 | consistent와 기존 보고서 해시 | 확인했다고 보고 |

기준 해시: `675dfa6fa3126da0ba74b5a4b4c4222afff4d950297703f3314788f9135a30db`. 실행 연습에서는 지원자가 전체 일치 검사 출력과 해시를 전달했다. 이번 계측 회차에서는 세 가지 결과 확인 여부를 전달했으며 전체 로그를 다시 받지는 않았다.

## 실제 전달받은 결과와 출처

- 총 경과 시간: **100초**, 1회. 반올림 여부와 스톱워치 해상도는 미확인이다.
- 세 가지 결과 확인: 완료했다고 보고했다.
- 오류·중단·외부 도움: 없었다고 보고했다. 이는 계측 중 추가 도움에 대한 응답이다. 이전의 Codex 명령·해석·기대값·측정 절차 안내는 있었다.
- 결과는 지원자의 자기 보고다. Codex가 맥북 화면·스톱워치를 관찰하지 않았으며 원본 계측 파일이나 계측 회차 전체 로그는 받지 않았다.
- 정확한 Python 패치 버전, macOS 버전과 다운로드 ZIP의 소스 커밋은 미확인이다. 해당 장치·입력·연습 후 상태의 기록으로 한정한다.

[구조화 기록](../reports/applicant-participation.json)의 `scripted_rerun_timing`과 [직접 참여 기록](participation.md)을 함께 확인한다.

## 해석과 남은 한계

100초에는 프로그램 대기와 사람의 명령 입력·읽기가 함께 들어 있다. 이를 집중 작업 시간으로 부르거나 둘을 분리 계산할 근거가 없다. 기존 연습의 분석 명령 78.098초는 다른 회차이며 네 명령 전체 대기 시간을 뜻하지 않으므로 `100−78.098`을 사람 작업 시간으로 계산하지 않는다. 다른 장치의 기존 기계 실행 중앙값 22.74초와 비교해 시간 절감률을 만들지 않는다.

측정은 1회이며 중앙값·분산·안정적 속도·인과적인 개선 효과를 추정하지 않는다. 별도 수동 분석 방식과 대응 비교하지 않았으므로 **전체 SQL·통계 분석의 사람 수작업 기준선은 여전히 미측정**이다. 기존 [3개 규칙 검토표의 A/B 실측](human-comparison-results.md)과 합치지 않는다.

근거에 맞는 표현은 “안내받은 기존 분석을 맥북에서 직접 재실행하고 SQL/pandas 대조·보고서 일치를 확인했다. 연습 후 재실행과 세 가지 결과 확인의 총 경과 시간을 한 차례 측정해 100초로 기록했다”다. 전체 분석을 독립 설계했다거나 100초로 단축했다고 표현하지 않는다.
