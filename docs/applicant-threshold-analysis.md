## 예상과 실제 결과

실행 결과를 받기 전에 지원자는 기준을 높이면 대상 수강 건수는 감소하고 재방문율은 증가할 것으로 예상했다. 활동 빈도와 다음 주 활동 가능성을 이유로 들었다. Codex는 대상 감소는 포함 관계에서 따르지만 비율 증가는 검증할 가설이라고 구분했다.

| 첫 주 활동 | 분모 | 다음 주 활동 분자 | 재방문율 |
|---|---:|---:|---:|
| 1일 | 5,565 | 3,835 | 68.9% |
| 2일 | 4,803 | 3,992 | 83.1% |
| 3일 이상 | 13,154 | 12,476 | 94.8% |

지원자가 제출한 2일 이상 합산은 16,468/17,957=91.7%, 3일 이상은 12,476/13,154=94.8%다. 대상 4,803건 감소(기존 대상의 약 26.7%), 관찰 비율 차이 +3.1%p로 계산했다. Codex가 반올림 전 분수로 재계산해 확인했다. 이 차이는 활동을 늘린 개입 효과가 아니다.

## 가상 자료의 손계산 검증

첫 주 0일인 한 건을 제외한 7건에서 1일군 1/2=50.0%, 2일군 1/2=50.0%, 3일 이상군 2/3=66.7%를 지원자가 먼저 계산했다. 이후 실행 출력도 동일했다. Codex 역시 제출된 SQL과 가상 CSV로 별도 재실행해 세 행을 대조했다. 이 작은 예시는 해당 분류·집계 조건을 검증하며 모든 데이터 품질·경계값을 포괄하지 않는다.

## 제출한 판단과 해석

지원자는 재방문율이 높아져도 기존 대상의 약 26.7%를 제외하고, 제외된 2일군 중 3,992건도 재방문하므로 비율만으로 기준을 높이는 것은 적절하지 않다고 설명했다. 학습 의지·강좌 특성에 의한 교란을 들어 인과 결론을 보류하고, 강좌/개설기별 확인·로그 누락 점검·대상 감소 영향·필요시 A/B 테스트를 추가 검증으로 제안했다.

선택란 원문에는 `3일 이상 기준을 사용 / 보류`가 모두 남아 있다. **설명의 취지는 비율만을 근거로 한 기준 상향 보류**로 해석하되, 이를 지원자가 선택란에서 한 단어만 명시했다고 바꾸지 않는다. 원문을 JSON에 보존했다.

검토 의견: 대상 규모와 비율의 교환 관계, 상관/인과 구분을 고려한 판단이다. 이번 과제의 용도는 **활동 기준 변경의 타당성 검토**로 정리한다. 최적 기준이나 실제 안내 대상 정책의 확정은 아니다. 실제 채택에는 관찰 지표인지 지원 자원 배분 기준인지, 제외 비용이 무엇인지 추가 정의가 필요하다. Codex가 최초 과제에서 이 정책 용도와 비용을 고정하지 않았으므로 이를 지원자의 설명 부족이나 추가 과제의 사유로 삼지 않는다. 이 맥락 정리는 Codex의 후속 검토이며 지원자의 제출 문장에 소급하지 않는다.

## 검증과 재현

Codex는 기존에 재현한 OULAD 분석표에 제출 SQL을 실행해 실제 출력 3행을 대조했고, 저장소 보고서의 첫 주 활성 23,522건·다음 주 활동 20,303건 합계도 확인했다. 실제 CSV는 재배포하지 않는다. 가상 예시는 기존 의존성이 설치된 프로젝트 폴더에서 다음처럼 재현할 수 있다.

```bash
python - <<'PY'
from pathlib import Path
import duckdb
con = duckdb.connect(':memory:')
con.read_csv('evidence/applicant/activity-threshold-fixture.csv').create_view('mart')
con.sql(Path('evidence/applicant/activity-threshold.sql').read_text()).show()
PY
```

예상 결과는 위 손계산의 세 행이다. 실행 보조 코드는 Codex가 제공했다. 실수나 수정 이력이 있어야 한다는 이유로 실패 사례를 만들지 않았다. 이번 제출본은 검토·대조에서 통과했으며, 확인된 수정 과정이 없는 것을 그대로 기록한다.

이번 근거로 설명할 수 있는 것은 **기존 프로젝트를 참고한 기준 비교 SQL 제출, 가상 사례의 손계산·실행 대조, 대상 규모와 비율을 고려한 판단**이다. 독립적인 전체 프로젝트 설계, 실제 회사의 재방문 개선, 무힌트 숙련도 검증으로 확대하지 않는다. 약속한 세 단계는 종료했다.
