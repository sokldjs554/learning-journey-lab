# 실제 1인 검토표 기록 비교

2026-10-30 KST. 지원자가 직접 수행한 연습 A/B와 측정 6회 JSON을 제공했고, Codex가 기존 가져오기 검사로 검증했다. 개발자 자동 조작이나 가상의 참여자 데이터가 아니다. 공개 집계는 [human-comparison.json](../reports/human-comparison.json), 사전 절차는 [비교 프로토콜](human-comparison-protocol.md)이다.

## 작업과 조건

같은 OULAD 스냅샷의 3개 규칙에 대해 count/severity/status를 기록하고 모든 행을 원문과 대조한다. A는 직접 입력, B는 자동 채움 후 같은 대조·확인이다. SQL 실행·원인 분석·전체 파이프라인 비교는 포함하지 않는다.

지원자 자기 보고 1명, 노트북, 뷰포트 1440×688, 브라우저 식별 문자열 Chrome 138. 장치·신원은 독립 인증하지 않았다. 옆에 다른 사람이 없었다고 기록했지만 Codex의 대화 안내는 받았다. 같은 데이터를 메모리에 둔 warm cache이며 연습 2회의 시간은 미측정이다. 측정 순서는 사전 정의된 ABBAAB다.

## 실제 기록

| 측정 | 방식 | 작업 구간 | 제외 구간 | 자동 채움 | 누락 / 오류 / 미확인 |
|---|---|---:|---:|---:|---:|
| 1 | A | 51.77초 | 378.02초 | 0.00ms | 0 / 0 / 0 |
| 2 | B | 14.20초 | 0.00초 | 0.20ms | 0 / 0 / 0 |
| 3 | B | 6.81초 | 0.00초 | 0.30ms | 0 / 0 / 0 |
| 4 | A | 40.27초 | 0.00초 | 0.00ms | 0 / 0 / 0 |
| 5 | A | 24.65초 | 0.00초 | 0.00ms | 0 / 0 / 0 |
| 6 | B | 19.78초 | 0.00초 | 0.10ms | 0 / 0 / 0 |

A는 자동 채움이 없으며 JSON의 기계 시간 0을 표에 표시했다. B의 기계 시간은 작업 구간에 이미 포함되어 있으므로 더하지 않는다. 최초 보고서 로드·해시 검증은 115.70ms로 별도이며 사람의 설치·학습 시간이 아니다.

| 동일 작업의 관측 요약 | 수동 A | 자동 채움 B |
|---|---:|---:|
| 측정 회수 | 3회 | 3회 |
| 작업 구간 중앙값 | 40.27초 | 14.20초 |
| 작업 구간 범위 | 24.65–51.77초 | 6.81–19.78초 |
| 기록된 누락·오류·미확인 | 모두 0건 | 모두 0건 |

중앙값은 세 값을 정렬한 가운데 값이다. **이번 1인의 동일 검토표 기록에서 B의 작업 구간 중앙값이 A보다 26.06초 짧게 관측됐다.** 양 방식 모두 오류 0건이므로 오류 감소는 입증하지 못했다. 소표본 반복 측정을 독립 참여자 6명으로 취급하거나 유의성/인과효과를 주장하지 않는다.

## 제외 시간과 중간 개입

측정 1의 제외 378.02초는 JSON의 hidden 구간과 manual_pause 구간 합이다. 구간 연속성·합계와 실제 시작/종료 벽시계의 허용 오차를 검증했다. 해당 회차를 결과를 본 뒤 제거하지 않았다. 탭이 숨겨진 이유, 일시정지 중 생각·읽기·방해 여부는 파일만으로 알 수 없다.

측정 1과 2를 보고하는 사이에는 코드 작성 실습과 대화가 있었다. 측정 회차 사이의 간격은 작업 구간에 포함되지 않는다. 순서·정답 기억·학습·중단 효과를 분리할 수 없어 일반적인 자동화 절감률로 확대하지 않는다. A의 51.77→40.27→24.65초 변화도 학습 효과를 의심할 이유이지 확정 증거는 아니다.

## 검증과 재현

원본 SHA256: `28e191d96a7621c8d540491dde8d4884e5352f42ba61d78a90ea25d23cf517fc`. 원본 전체는 저장소에 공개하지 않았다. 공개 JSON은 상대 시간 구간·작업 결과·검사와 요약을 보존하고 정확한 시각 및 원문 환경 문자열은 제외한 파생 자료다. 원본을 가진 지원자는 다음을 실행할 수 있다.

```bash
python scripts/import_practice.py /path/to/downloaded-export.json
```

성공 시 `valid_measured_rounds: 6`, `all_measured_rounds_valid: true`, `comparison_ready: true`다. 이는 비교 가능한 기록 형식이라는 뜻이며 생산성 개선이나 신원을 인증하는 판정이 아니다. 다음은 공개 파생 자료만으로 중앙값을 다시 계산하는 방법이다.

```python
import json
from statistics import median
with open("reports/human-comparison.json", encoding="utf-8") as f:
    result = json.load(f)
for mode in ("A", "B"):
    values = [r["task_interval_ms"] / 1000 for r in result["rounds"] if r["mode"] == mode]
    print(mode, round(median(values), 2))
# A 40.27 / B 14.2
```

## 설명할 수 있는 사실과 남은 확인

지원자는 안내를 받아 같은 3개 품질 규칙의 검토표 기록을 두 방식으로 각 3회 수행하고 원본 기록을 제공했다. Codex는 도구·절차를 만들고 파일 검증·요약·문서 반영을 수행했다. 독립적인 실험 설계나 회사 업무의 시간 절감으로 쓰지 않는다.

보다 일반적인 비교에는 새로운 데이터 과제, 순서를 무작위화한 여러 참여자, 중간 개입 없는 세션과 동일 대조 수준의 관찰이 필요하다. 이번 지원자는 이미 안내받은 경험이 있으므로 이 결과를 처음 보는 사람의 사용성 검토로 재사용하지 않는다. 실제 서비스 실험은 여전히 미실시다. 이후 별도 참여자 1명의 데모 사용성 응답을 받은 기록은 [사용성 검토](usability-results.md)에 분리했다. 이 지원자의 작업 시간 비교와 합산하지 않는다.
