## 실측 진행과 아직 남은 확인
- 사용자가 대화에 붙여넣은 표: A·B 연습 모두 유효. 연습 시간은 미기록, B 자동 채움 0.20ms. 측정 1 A는 작업 구간 51.77초·제외 구간 378.02초·유효로 표시됐다.
- 위 수치는 사용자 제공 화면 표의 표시값이다. 전체 JSON 내보내기를 아직 받지 않아 원본 구간·환경·유효성은 독립 검증 전이다. 활성 구간을 집중 노동 시간으로 확정하지 않으며, 378.02초의 원인을 추정하지 않는다.
- 이후 사용자가 측정 2 B 표도 전달했다: 작업 구간 14.20초·제외 0.00초·자동 채움 0.20ms·유효. 측정 1과 2의 보고 사이에 코드 실습을 진행한 대화 맥락을 남긴다. 정확한 시간 관계는 전체 JSON 확인 전이다.
- 남은 B/A/A/B 측정과 전체 JSON 검증이 필요하다. 자동화 대비 시간·오류 절감률은 아직 계산하지 않는다.
- 새 참여자의 사용성 검토는 미실시. 안내받은 실습과 개발자 브라우저 테스트를 처음 보는 사용자의 평가로 바꾸지 않는다.
