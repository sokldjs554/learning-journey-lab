## 실제 기기·VoiceOver 확장 QA 정리 (2026-11-02 KST)

지원자가 상세 탭·표·분모·계획 표본·생성 로그·EdNet 출처를 읽고 조작 결과를 전달했다. 실습 누락 설명·무효 판정·준비 복귀, Safari200%/400% 확대 후 읽기·조작, Android회전·확대·표 스크롤·터치 취소도 보고했다. 메인/EdNet의 오류 문구·키보드 재시도·제목 읽기 보고는 실습 자동 복구 보고와 구분했다. [증거·정정·범위](accessibility-human-results.md). Codex가 기대값·조작법을 안내했으며 독립 사용성 연구나 모든 상태의 접근성 인증이 아니다. 사용자 재확인은 종료하고 받은 근거로 정리했다.

## v2 전체 운영 사람 실측 종료 (2026-11-05 KST)

지원자가 연습 A/B 뒤 본 측정 ABBAAB 완료 6회·next null·로컬 감사 PASS 요약을 전달했다. 연습 중단 1회와 본 측정 중단 1회를 모두 보존했다. 본 측정 A 3완료·1중단의 경과 합계 1,426.62초, B 3완료의 합계 356.57초다. Codex가 순서·개수·시간 산술을 대조했다. ## 별도 선택한 직접 구현 범위

사용자는 UI·배포까지 포함한 전체 프로젝트 직접 구현을 선택했다. [고정 요구사항·역할·첫 제출](independent-implementation-brief.md)을 준비했다. 이 문서는 Codex의 과제 안내이며 새 구현의 코드 제출·완료 근거가 아니다. 기존 직접 제출 SQL은 재사용 가능한 완료 근거로 유지한다.
