지원자는 저장소 ZIP을 내려받고 가상환경에서 안내된 명령을 실행했다. Python 버전은 처음 3.13이라고 했으나 설치 경로와 추가 답변을 통해 3.14로 정정했다. 정확한 패치 버전과 ZIP의 소스 커밋은 확인하지 않았다. 아래는 지원자가 전달한 출력이며 Codex가 맥북 세션을 직접 관찰한 결과는 아니다.

- 다운로드 출력: CSV 7개 검증·압축 해제 완료.

- build/verify 안내 후 받은 일치 검사 출력: 보고서·UI·README·findings·benchmark·crosscheck 일치. 보고서 SHA256 `675dfa6fa3126da0ba74b5a4b4c4222afff4d950297703f3314788f9135a30db`로 기존 결과와 같다.

[전달받은 결과의 구조화 기록](../reports/applicant-participation.json). 지원자의 직접 수행은 안내받은 로컬 실행과 결과 전달이다. 코드·분석 독립 설계, 전체 원본의 무오류, Python 3.14의 모든 플랫폼 호환성을 증명하지 않는다. 이번은 설치·실행 연습이며 전체 분석의 사람 수작업 기준선이나 자동화 시간 절감 측정은 아직 아니다. 78.098초를 기존 서버 실행 시간 또는 수작업 실측과 빼서 개선율을 계산하지 않는다.

## 직접 SQL 확인과 재실행 시간 (2026-10-31 KST)

지원자는 제공된 읽기 전용 SQL을 실행해 등록일 결측 45행을 확인했다. 등록일을 임의로 0으로 채우면 확인되지 않은 날짜를 개강일 등록으로 간주하게 된다는 이유를 본인 말로 설명했다. Codex는 그 가정이 분모를 바꿀 수 있으며 모든 결측 대체가 잘못인 것은 아니라고 보충했다. SQL 독립 작성으로 표현하지 않는다. 보고서의 REVIEW 5개 항목 출력도 전달했다.

이후 기존 `analyze → crosscheck → build → verify` 명령을 순차 실행하고 안내된 세 결과를 확인하는 회차를 1회 측정했다. **전체 경과 100초, 세 결과 확인, 오류·중단·계측 중 추가 도움 없음**을 보고했다. 사전 Codex 안내는 있었으며 100초는 실행 대기를 포함한 자기 보고다. [측정 범위·해석·미확인 항목](local-rerun-results.md). 전체 분석의 수작업 시간이나 자동화 절감률로 바꾸지 않는다.
