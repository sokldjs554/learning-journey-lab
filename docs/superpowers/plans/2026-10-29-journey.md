# Learning Journey Lab Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Inline execution; whole-project reviewer after implementation.

**Goal:** 로그 신뢰성에서 첫 주 학습과 다음 주 재방문 판단까지 재현 가능한 증거를 만든다.
**Architecture:** immutable CSV → DuckDB SQL checks/marts → Python estimates → versioned JSON → static evidence UI.
**Tech Stack:** Python 3.12, DuckDB 1.4.3, pytest, NumPy, vanilla HTML/CSS/JS, Playwright.
**Spec:** ../specs/2026-10-29-journey-design.md

## Global Constraints
공개/생성 데이터 완전 분리. 관찰=인과 아님. day 0~6/7~13 고정. 전체 결과와 UI/README 수치 일치. 외부 데이터는 SHA256 검증. 새 저장소만 수정. 사용자 공개 배포 요청은 허가됨; Render 대상 공간 선택 필요.

## Review Focus
- 0,6,7,13,14일 경계와 zero-click 활동
- 결측 등록일/개강 전 탈퇴 분모 및 미래 탈퇴 제거 위험
- 중복/충돌 키가 JOIN으로 증식하거나 집계 결과를 바꾸는 경우
- 2013/2014 반복 학습자의 검증셋 누수
- 빈 필터/잘못된 JSON/키보드/모바일 화면

## Task 1: Data contract and reproducible acquisition
Files: scripts/download.py, data/manifest.json, docs/research/sources.md, tests/test_download.py.
- [x] Verify fixture archive hash mismatch fails before extraction, unsafe archive paths rejected.
- [x] Implement fixed URL and SHA256; preserve existing files, validate cached data; no silent synthetic fallback.

## Task 2: SQL quality and metrics
Files: src/journey/pipeline.py, sql/quality.sql, sql/marts.sql, tests/test_metrics.py.
Interfaces: build_marts(connection) consumes typed source tables; produces enrollment mart. quality(connection) returns rule counts.
- [x] Hand fixture assertions: explicit enrollment counts, boundary-day flags, duplicates, unknown keys, nonpositive clicks, null registration, post-withdrawal warning.
- [x] Run red; implement SQL and Python IO; run green.
- [x] Full dataset run; independent pandas cross-check for bounded first fortnight; report ambiguous row policies.

## Task 3: Statistics and fault lab
Files: src/journey/statistics.py, src/journey/faults.py, sql/faults.sql, tests/test_statistics.py, tests/test_faults.py.
Interfaces: estimate(mart) returns group counts, cluster intervals, temporal/stratum results; fault_lab() returns ground-truth, observed, cleaned, replay stages and rule evidence.
- [x] Hand 12-person test: 10 W1 active, 6 W2 returns, 60% truth; mutation/loss remain visible until replay.
- [x] Verify empty/constant samples, cluster handling and disjoint holdout; run red then green.
- [x] Export deterministic report, issue registry, benchmark run times; rerun and compare hashes.

## Task 4: Evidence UI and documentation
Files: web/index.html, web/style.css, web/app.js, scripts/build.py, tests/browser_check.py, README.md, docs/*.
Interfaces: web/data/report.json is the exact analytics report; no hand-entered metrics.
