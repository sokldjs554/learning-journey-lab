# Learning Journey Lab — 첫 주 학습 신호 점검

## 목적과 판단
제품전략팀 DA가 재방문 개선안을 논의하기 전에 학습 활동 지표를 신뢰해도 되는지 판단하는 작은 분석·운영 도구. 공개 OULAD 분석과 완전히 별도인 생성 이벤트 장애 실습을 한 의사결정 흐름으로 연결한다. CLASS101 내부 데이터, 실제 서비스 실험, 매출 효과를 주장하지 않는다.

## 비교한 접근과 선택
1. OULAD 일별 활동 + 품질 게이트 + 재방문 분석: CC BY 4.0, 약 45MB 압축, 등록·콘텐츠 키 검증 가능. 일내 순서·영상 시청·구독 갱신은 관측 불가. 선택.
2. EdNet KT4 세션/결제 분석: 풍부한 이벤트지만 1.2GB 압축, TOEIC 학습 맥락, CC BY-NC 4.0 및 이동된 타임스탬프. 빠르게 독립 재현하는 면접 자료에는 비용이 크다. 미채택.
3. HarvardX person-course: 실제 수강 데이터지만 개인-강좌 요약만으로 첫 주 재방문과 이벤트 검증 불가. 미채택.
선택은 사용자의 조사 후 범위 결정 위임에 따라 에이전트가 내렸다.

## 분석 계약
- 원본 7 CSV 보존, 다운로드 SHA256 고정. 공개 화면은 집계만 노출한다.
- 분석 단위: 학습자×모듈×개설기. 반복 수강을 한 사람으로 오인하지 않는다.
- day 0=개강일. 첫 주=0~6, 다음 주=7~13, 후속 확인=14~27. 개강 전 활동은 유효하나 해당 지표에서 제외.
- 코호트: 등록일 존재, 등록일<=0, 탈퇴일 null 또는 >=0, 개설 길이>=28. 이후 탈퇴자를 미래 정보로 분모에서 제거하지 않는다.
- W1 활성: 유효 양수 클릭이 첫 주 하루 이상. W2 재방문: W1 활성 중 다음 주 하루 이상 활동. 영상 수강률·연간 리텐션이 아니다.
- 가설: 첫 주 하루만 활동한 그룹이 2일 이상 활동한 그룹보다 다음 주 재방문이 낮다. 추가 가설: 첫 활성일 콘텐츠 접촉이 관계를 보이는가. 탐색적 가설이며 이미 공개된 데이터에 대한 진정한 사전등록은 아니다.
- 2013 탐색 / 2014 재확인. 재확인에서는 2013에 등장한 학습자를 제외하고 별도 보고. 결과를 보기 전 경계·주요 그룹을 고정.
- 신뢰구간: 학습자 단위 군집 부트스트랩으로 반복 수강 의존성 반영. 개설기 내 비교, B/J 구분, 지표 정의 민감도. 인과 효과 주장 금지.

## 품질과 자동화
SQL로 필수값/복합키 중복/참조 키/클릭 범위/등록 시점 관계/모듈 기간을 확인한다. 일별 집계에서 관측할 수 없는 이벤트 누락·순서 오류는 미검증으로 명시한다. 등록 전후 활동은 바로 삭제하지 않고 경고와 민감도 분석에 남긴다. 중복의 출처가 불명확한 경우 합산·제거 양쪽 영향을 보고한다.
별도 생성 실습: 고정 ground truth 12명, W1 10명, W2 6명. 누락·중복·잘못된 키·순서·지연 수집을 의도적으로 주입한다. 수정 가능과 원본 재수집 필요를 구분하며 손실 데이터를 추정 복원하지 않는다. 안정적 issue ID, 상태 이력, 반복 실행 시 동일 출력, 배포용 결과에 품질 gate 포함.
자동화 시간은 실제 벤치마크만 기록. 사람 수작업 시간·회사 생산성 향상은 미측정. 수작업 비교 프로토콜 제공.

## UI
차분한 밝은 바탕, 짙은 네이비와 단색 강조. 제목은 명사형. 첫 화면 판단→분모/범위→실제 분석→품질 실습→액션. 개설기 필터, 표/차트, 품질 규칙 상세, 장애 시나리오 선택, 근거 JSON 다운로드. 공개/생성 배지 고정. PC/모바일/키보드/빈 데이터/로드 실패를 브라우저에서 확인. 정적 HTML/CSS/JS, 서버 점검·알림 발송 기능 없음.

## 구현 경계
Python+DuckDB SQL+NumPy 통계, 정적 웹. AI API 불필요. 원본은 git에 넣지 않는다. 집계 결과 하나를 화면·보고서·README의 공통 출처로 사용한다. Python 3.12 기준. 새 빈 저장소만 사용; 기존 /workspace의 다른 프로젝트 수정 금지. Render 배포 작업 공간은 사용자 선택 대기.
