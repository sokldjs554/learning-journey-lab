같은 검토 표, 두 가지 기록 방법

이미 계산된 품질 규칙 3개의 건수·심각도·상태를 옮기고, 각 행을 원문과 대조합니다. 전체 SQL 분석 시간의 비교가 아닙니다.

지원자 1명이 수작업 A와 자동 채움 B를 각 3회 완료했습니다. 실측 결과와 한계를 확인하세요. 이 화면은 브라우저 안에서만 기록하며, 완료 후 JSON 파일로 내보냅니다. 서버 전송·자동 저장은 없고, 새로고침하면 기록이 사라집니다.

작업과 측정 조건

  1. A 수작업: 아래 원문 표의 건수·심각도를 직접 옮기고, 건수가 0이면 clear, 양수이면 open을 고릅니다.
  2. B 자동 채움: 같은 원문에서 세 필드를 자동 입력합니다. A와 똑같이 모든 행을 대조하고 확인 상자를 선택합니다.
  3. A·B를 각각 한 번 정확히 연습한 뒤, A → B → B → A → A → B 순으로 6회 측정합니다. 연습·안내 읽기·설치 시간은 측정에서 제외됩니다.

시작~완료 사이 사용자가 조절하는 작업 구간을 기록합니다. 주의 집중이나 실제 노동 시간을 보장하지 않습니다. 일시정지와 탭 숨김은 제외 구간으로 따로 남기며, 돌아오면 재개를 눌러야 합니다.

동일 스냅샷을 브라우저 메모리에서 반복 사용하므로 캐시는 따뜻한 상태입니다. 같은 값을 기억하는 학습 효과와 장치·숙련 차이는 남습니다. ABBAAB 순서는 이를 완전히 제거하지 않습니다.
