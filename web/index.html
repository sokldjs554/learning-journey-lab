P0

학습 기록의 누락 확인

학습자가 남긴 기록이 분석할 때 빠지거나 두 번 들어오지 않았는지 확인하는 준비 단계입니다. 기록 누락을 학습 이탈로 오판하지 않기 위해 필요합니다.

현재 상태
생성 데이터에서 검사 방법을 확인했습니다. 실제 서비스의 원천 기록과 수신 기록 대조는 미실시입니다.
기록 기준
event_id, 발생·수신 시각, 세션 키, 원천 전송 명세를 정의합니다. 누락이나 실험 그룹 배정 오류가 있으면 결과 해석을 보류합니다.
필요 근거
실제 이벤트 명세, 지연 분포, 누락 대조, 기기별 오류
제안 역할
분석가 + 클라이언트·데이터 개발자
기대 영향
누락을 학습 이탈로 오판할 위험 감소. 크기 미측정.

P1

다음 학습 안내 비교

첫 학습을 마친 사람에게 다음에 어디서 이어 들을지 안내하는 화면과 현재 화면을 비교하는 제안입니다. 안내를 받은 그룹에서 이후 학습을 위해 돌아오는 사람의 비율이 더 높은지 확인하려고 합니다.

현재 상태
실험 설계만 완료했습니다. 실제 서비스에서 두 화면을 비교하지 않았고, 재방문 개선 효과는 모릅니다.
비교 전 확인
기존 퀴즈·연속 수강 기능과의 중복은 현행 서비스 관찰 후 조정합니다.
대상·배정
개별 구독의 신규 첫 학습자, 계정 단위 1:1 무작위 배정. 그룹 구독은 별도 설계.
주요 지표
첫 학습 종료 기준 D7–13에 한 번 이상 유효 학습을 한 비율. 배정된 전체를 원래 배정대로 비교(ITT).
해석 조건
A/A·배정비율(SRM)·로그 누락 확인, 마지막 배정 후 14일 경과 + 수신 유예. 중간 유의성으로 조기 종료하지 않음.
함께 볼 문제
재생 오류, 불만, 알림 해제, 환불. 연간 갱신은 별도 장기 추적.
P2

먼저 확인
학습 목적·강좌 구성·유입·권한·콘텐츠 종료 이력. 콘텐츠를 더 보여주면 재방문이 늘어나는지는 아직 검증하지 않았습니다.
